### 【任务背景】

本任务针对 **桌面端 GUI 界面** 的动态理解。
假设已具备：

* 单帧图像的多模型识别能力（包括 OCR、检测、分割、embedding 等）；
* 可自动控制键盘与鼠标的脚本系统。

当前问题是：
在执行一次动作后，界面图像会发生变化，而**仅依赖单帧识别无法正确判断任务状态或执行精确动作**。
因此，需要识别并解释**两帧图像之间的差异与变化类型**。

---

### 【任务目标】

给定 **前一帧图像（state_before）** 与 **后一帧图像（state_after）**，
识别并分析它们之间的主要变化内容，用于支撑 GUI 自动化的状态判断与任务决策。

---

### 【要求模型具备的处理能力】

你可以使用任意开源模型与工具，包括但不限于：

* 图像检测与分割模型（如 YOLO、SAM、Mask2Former 等）；
* 语义匹配与变换识别模型（如 CLIP、RAFT、Optical Flow）；
* 多模态模型（如 Florence-2、BLIP、OFA、Grounding DINO 等）。

---

### 【输出期望】

请返回或构思以下四个层次的结果或方法：

1. **图像变化区域检测（必须实现）**

   * 输出：变化区域的二维位置（bbox 或 mask）。
   * 目标：标出界面中主要变化的区域。
   * 方法方向：图像差分 / 光流 / 匹配特征点 / 实例跟踪。

2. **变化区域语义理解（构思方案）**

   * 输出：变化的内容是什么（出现、消失、移动、旋转、弹窗等）。
   * 方法方向：跨帧实例匹配 + embedding 相似度 + OCR 变化分析。

3. **变化与动作关联（构思方案）**

   * 输出：推理“该变化可能由什么动作导致”。
   * 方法方向：利用动作日志（鼠标/键盘）与变化区域空间关系进行因果关联。

4. **未来变化预测（构思方案）**

   * 输出：根据当前变化，预测下一次执行动作后可能的变化趋势。
   * 方法方向：基于历史状态序列的语义建模（RNN / Transformer / 差分特征趋势）。
